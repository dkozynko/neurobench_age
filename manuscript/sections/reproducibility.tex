\section{Reproducibility and Artifact Integrity}

The experiment used an immutable study lock, a complete content-addressed
checkpoint inventory, create-only external predictions, and analysis permitted
only after an exact completion marker. The retained compact bundle contains no
raw EEG, model weights, checkpoints, representation caches, participant-level
predictions, or private storage paths. Instead it records counts, aggregate and
per-seed statistics, bounded resource summaries, and the hashes needed to bind
those summaries to the external artifacts.

All reported primary values, table rows, and figures are generated from the
compact confirmatory artifact. Hand-authored section files reference LaTeX
commands rather than duplicating result literals. The source analysis identity
is \texttt{\SourceAnalysisHash}; the full external prediction inventory
identity is \texttt{\PredictionInventoryHash}. A renderer validates the compact
manifest, writes into a temporary directory, hashes every payload, and publishes
only a complete bundle. Fixed ordering, plotting configuration, fonts, and PDF
metadata make two clean asset builds byte-identical.

These artifacts provide content-addressed auditability and exact re-execution
metadata, but they do not by themselves make participant-level metrics
independently recomputable from the Git repository: the underlying EEG,
checkpoints, and prediction vectors remain external. An independent rerun
therefore requires the declared data-access path and the sealed environment.

The codebase also keeps evidence classes explicit. Prospective MIPDB evidence
supports the confirmatory conclusion; official NeuralBench-style end-to-end
experiments support reproduction context; historical HBN test results remain
retrospective. This prevents an already inspected split from silently becoming
new confirmatory evidence.

\paragraph{Code and data availability.}
The analysis code, executable protocol, validation tests, compact aggregate
evidence, and deterministic manuscript renderer are included with the study
materials. The primary source-analysis identity is
\texttt{\SourceAnalysisHash}, and the external prediction inventory is bound by
\texttt{\PredictionInventoryHash}. Raw HBN and MIPDB recordings, REVE weights,
representation caches, and participant-level prediction vectors are not
redistributed in the compact release. A rerun therefore requires the declared
dataset access permissions and the corresponding content-addressed artifacts;
the release is intended to support auditability and controlled reproduction,
not unrestricted redistribution of participant data.
