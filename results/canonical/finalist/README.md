# Historical HBN finalist records

`final_gate.json` and `final_comparison.json` record an earlier HBN finalist
workflow. They are retrospective secondary evidence because HBN R5 has since
been used in repeated decisions. The label `finalist` is historical and does
not mean that these files provide untouched confirmation.

The records must not be used for model or head selection in the prospective
frozen representation study. Associated checkpoints and full predictions are
external artifacts.
