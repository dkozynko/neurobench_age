# Canonical evidence

This directory contains compact, content-addressed records from the completed
prospective study and earlier HBN experiments. Start with
[`index.json`](index.json), then use the evidence taxonomy in
[`docs/research/article_evidence_registry.md`](../../docs/research/article_evidence_registry.md).

`prospective/` contains aggregate confirmatory statistics and provenance
identities for the sealed external evaluation: 40 runs, 75 primary subjects,
and a 3,000-record prediction inventory. It intentionally excludes prediction
rows and participant identifiers.

HBN R5 has already been opened during repeated finalist decisions. Therefore
every result here is retrospective secondary evidence: it may document prior
behavior and motivate hypotheses, but it must not be used for model or head
selection and cannot provide untouched confirmation.

Raw checkpoints, EEG, prediction dumps, representation caches, and launch logs
remain outside Git. `legacy_screening/` contains historical compact metrics only.
